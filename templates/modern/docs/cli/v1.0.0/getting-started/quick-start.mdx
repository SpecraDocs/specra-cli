## Create a Project

```bash
platform init my-docs
```

You'll be prompted to choose a template and package manager.

## Start Development

```bash
cd my-docs
npm run dev
```

## Project Structure

```
my-docs/
├── docs/           # Your documentation content
├── src/            # SvelteKit routes and components
├── static/         # Static assets
├── specra.config.json
└── package.json
```
