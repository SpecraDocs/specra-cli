## Usage

```bash
platform dev
```

## Features

- Hot module replacement (HMR)
- Instant page loads
- Auto-refresh on content changes
- Error overlay with stack traces

## Options

| Option | Description |
|--------|-------------|
| `--port` | Port number (default: 5173) |
| `--host` | Expose to network |
