## Usage

```bash
platform deploy [target]
```

## Targets

| Target | Description |
|--------|-------------|
| `vercel` | Deploy to Vercel |
| `netlify` | Deploy to Netlify |
| `gh-pages` | Deploy to GitHub Pages |

## Example

```bash
platform build
platform deploy vercel
```
