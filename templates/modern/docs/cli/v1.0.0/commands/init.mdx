## Usage

```bash
platform init [project-name] [options]
```

## Options

| Option | Description |
|--------|-------------|
| `--template` | Template to use (minimal, book-docs, jbrains-docs, modern) |
| `--pm` | Package manager (npm, yarn, pnpm) |

## Examples

```bash
platform init my-docs --template modern --pm pnpm
```
